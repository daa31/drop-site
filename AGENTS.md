# FORTIS — спеціалізований інтернет-магазин захисту зору

Власний бренд і вітрина. Асортимент узгоджено з публічним каталогом постачальника (артикули, моделі, ціни), без копіювання дизайну UAbest.

- Next.js 15, TypeScript, Tailwind, Prisma, SQLite
- Мови: українська (за замовчуванням), російська, англійська
- Дропшиппінг: імпорт, МРЦ, націнка, замовлення, ТТН, Telegram
